## 翻译服务商改为页面可配置

需求：翻译 API 做成页面可设置，默认用免费的，也能改成个人 API Key。

实现（无新增依赖）：
- 新增 `src/lib/translate-settings.ts`：账号级设置存 `data/users/<id>/settings.json`，文件不存在即跟随站点默认（老账号零迁移）；`maskApiKey` 只回传尾巴。
- 新增 `src/pages/api/settings.ts`（GET/PUT）与 `src/pages/settings.astro`（`/settings`）。
- `getProvider(settings?)` 支持账号自选；`customProvider(url, apiKey)` 支持 `{key}` 占位，未写 `{key}` 时走 `Authorization: Bearer`；带 key 时 provider id 为 `custom-key`，与站点默认的 `custom` 分开缓存。
- `translatePage` / `translateRange` 的 options 新增 `settings`，一路透传到 `api/translate.ts` 与阅读页。
- `site.ts` 新增 `translation.userConfigurable` 总开关。
- 阅读页缓存渲染增加 provider 一致性校验：换引擎后旧译文不再顶替。
- 顶栏头像菜单加「翻译设置」入口。

约定：
- PUT 未传的字段一律保留，传空字符串才是清空（apiUrl 与 apiKey 语义一致）。这条踩过一次：最初 apiUrl 默认转成 ''，导致切回默认就丢了地址。
- 密钥不回传明文，前端留空表示不修改。

验证：`astro check` 0 错误；`npm test` 61 条全通过；`npm run build` 通过；`PORT=4400 npm run start` 起来后实测登录 / GET / PUT / 校验分支 / 切换 / 清除密钥全链路正常。测试数据已清理（admin 的 settings.json 已删，users.json 的 lastLoginAt 已 git restore）。

注意：本机 4321 端口被既有进程占用，验证用 4400，未动原进程。

## 新增「中文阅读」（与英文阅读分开）

需求：加中文阅读，不需要翻译，和英文阅读分开。

实现（无新增依赖，无数据迁移）：
- `ArticleRecord` 加可选 `lang: 'en' | 'zh'`，老数据缺省按 `'en'`（`articleLang()` 归一化）；`ArticleSummary.lang` 总是有值。
- 同一份存储 `data/users/<id>/articles/*.json`，不新增目录 —— 刻意没走"独立存储/独立路由"的替代方案，避免复制 CRUD。
- 导入：`/import` 加语言单选，`?lang=zh` 可预选；`POST /api/articles` 收 `lang`。中文按汉字计字数（`countChineseChars`），`toBlocks(raw,'zh')` 合并行不插空格。
- 列表分开：首页 `/` 只列英文，新增 `/zh` 只列中文；导航改成 英文阅读 / 中文阅读 / 导入 / 生词本 / 关于我。
- 阅读页同一路由分支：中文不渲染 `.word`、不显示全文翻译与「本文生词」侧栏、`translation.enabled=false`；分页用 `siteConfig.zhReader.charsPerPage`（1200 字/页，英文 3000 字符/页）。
- 关键技巧：`reader.ts`（点词/生词）改成**动态 import**，只在 `lang !== 'zh'` 时加载 —— 这样完全没改 reader.ts 一行代码，Vite 也把它拆成独立 chunk。
- 新账号欢迎文章变成英文 + 中文各一篇（`seed.ts`），因此 `tests/e2e.test.mjs` 里"B 只有 1 篇欢迎文章"改成 2 篇；新增 1 条中文阅读回归用例 → 测试 61 → 62。

验证：`astro check` 0 错误；`npm test` 62 条全通过；`npm run build` 通过；临时 DATA_DIR + 4399 端口实测：中文示例只在 `/zh`、首页 0 命中、中文阅读页 `class="word"` 与 `id="article-vocab"` 均为 0、英文页仍 224 个 `.word` 且翻译 `enabled:true`、1680 字中文长文按 1200 字/页分成 2 页。

注意：本机 4321 上跑着 `npm run start`（真实 data/），验证用临时目录 + 4399，未污染真实数据。
